# Phase 19 -- UI Design Contract

> Visual and interaction contract for Hero Stats & Collection Overview. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn v4 |
| Preset | base-nova (neutral base) |
| Component library | @base-ui/react |
| Icon library | lucide-react |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, metric bar divider margins |
| sm | 8px | Compact element spacing, chart legend gaps |
| md | 16px | Default element spacing, card padding, chart grid gap |
| lg | 24px | Section padding, card internal content spacing |
| xl | 32px | Layout gaps between major sections (metrics bar to lifetime, lifetime to charts) |
| 2xl | 48px | Major section breaks (reserved, not expected in this phase) |
| 3xl | 64px | Page-level spacing (reserved, not expected in this phase) |

Exceptions: none

| Role | Size | Weight | Line Height | Font Family | Usage in Phase 19 |
|------|------|--------|-------------|-------------|-------------------|

### Chart Color Assignments

**Status donut** (existing, no change):
Uses `--status-*` tokens (7 colors mapped to ProjectStatus enum).

**Size category bar chart** (5 bars, ordered Mini through BAP):

| Category | Token | Color |
|----------|-------|-------|
| Mini | `--chart-1` | emerald-600 |
| Small | `--chart-2` | amber-500 |
| Medium | `--chart-3` | sky-500 |
| Large | `--chart-4` | violet-600 |
| BAP | `--chart-5` | rose-600 |

**Designer bar chart** (top 10, horizontal):
Use `--chart-1` (emerald-600) as the single uniform bar color for all designers. Uniform color prevents visual noise and keeps focus on bar length comparison, which is the primary information channel.

**Genre bar chart** (top 10, horizontal):
Use `--chart-3` (sky-500) as the single uniform bar color for all genres. Distinct from designer emerald to visually differentiate the two horizontal charts when side-by-side in the 2x2 grid.

## Component Inventory

### 1. MetricsBar (new, client component)

**Purpose:** Condensed horizontal strip showing time-window stitch counts (D-01).

**Structure:**
- Single `bg-success-muted border border-success-border rounded-xl` container
- 4 metric cells in a horizontal flex row, separated by subtle vertical dividers
- Each cell: icon (16px lucide) + uppercase label (11px) above, stitch count (30px mono) below, "stitches" unit (12px muted)
- Dividers: 1px `border-success-border` vertical line, `h-12` height, centered

**Icons per cell:**
- Today: `Zap` (from DesignOS HeroStats)
- This Week: `CalendarDays`
- This Month: `CalendarRange`
- This Year: `TrendingUp`

**Responsive:** 4 columns at `sm:` breakpoint and above. Below `sm:`, 2x2 grid with horizontal dividers between rows.

**Empty state:** Show "0" for each counter (not hidden). Zero is a valid display state.

**Data source:** `StatsHeroData.stitchesToday/stitchesThisWeek/stitchesThisMonth/stitchesThisYear`

### 2. LifetimeCounters (new, server component)

**Purpose:** 4 stat cards showing lifetime totals (D-02).

**Structure:**
- Section heading: Fraunces 14px semibold with lucide icon (16px, `text-success`)
- 4 cards in `grid grid-cols-2 sm:grid-cols-4 gap-4`
- Each card: `bg-card` with `ring-1 ring-foreground/10 rounded-xl p-4`
- Card content: label (text-xs text-muted-foreground uppercase tracking-wider) + value (text-lg font-mono font-semibold tabular-nums)

**Cards:**

| Label | Value Source | Format |
|-------|-------------|--------|
| TOTAL STITCHES | `totalLifetimeStitches` | `toLocaleString()` |
| SESSIONS | `totalSessions` | `toLocaleString()` |
| TIME STITCHING | `totalTimeMinutes` | `formatTime()` (e.g., "42h 15m") |
| COMPLETED | `projectsCompleted` | `toLocaleString()` |

**Section icon:** `FolderOpen` (matches DesignOS StatCards pattern)

**Empty state:** Show "0" / "0h" for each. No special empty state component needed.

### 3. CollectionStatusChart (existing, no changes)

Already built in Phase 18. Donut chart using `--status-*` tokens. No modifications needed (D-07).

### 4. SizeCategoryChart (new, client component)

**Purpose:** Vertical bar chart showing project count by size bucket (D-04).

**Structure:**
- Recharts `BarChart` with `Bar` + `XAxis` + `YAxis` + `Cell` inside `ChartContainer`
- X-axis: 5 category labels ("Mini", "Small", "Medium", "Large", "BAP")
- Y-axis: project count (integer)
- Each bar colored per size category (see chart color table above)
- Wrapped in a card container with heading: "Collection by Size"

**Dimensions:** `h-[250px]` (matches status donut height for grid alignment)

**Empty state:** If no projects exist, show centered muted text "No projects yet" (same pattern as CollectionStatusChart).

**Data source:** New query `getSizeBreakdown(userId)` returning `{ category: string; count: number; fill: string }[]`

### 5. DesignerBreakdownChart (new, client component)

**Purpose:** Horizontal bar chart showing top N designers by chart count (D-05).

**Structure:**
- Recharts `BarChart layout="vertical"` with `Bar` + `XAxis` + `YAxis`
- Y-axis: designer names (truncated at 20 chars with ellipsis via `tick` formatter)
- X-axis: project count (integer)
- All bars use `--chart-1` (emerald) uniform fill
- Wrapped in a card container with heading: "Top Designers"

**Top N count:** 10 designers (Claude's discretion). If fewer than 10 exist, show all. If zero, show empty state.

**Dimensions:** `h-[300px]` (taller than status/size charts to accommodate 10 rows)

**Empty state:** "No designers yet" centered muted text.

**Data source:** New query `getDesignerBreakdown(userId, limit: 10)` returning `{ designerId: string; name: string; count: number }[]`

### 6. GenreDistributionChart (new, client component)

**Purpose:** Horizontal bar chart showing genre distribution (D-06).

**Structure:** Identical layout pattern to DesignerBreakdownChart except:
- All bars use `--chart-3` (sky) uniform fill
- Heading: "Genre Distribution"
- Y-axis: genre names

**Top N count:** 10 genres.

**Dimensions:** `h-[300px]`

**Empty state:** "No genres yet" centered muted text.

**Data source:** New query `getGenreBreakdown(userId, limit: 10)` returning `{ genreId: string; name: string; count: number }[]`

### 7. RankedList (new, server component)

**Purpose:** Clickable ranked list below each breakdown chart, providing entity navigation (D-10, D-12, INS-06).

**Structure:**
- Rendered below each chart card as a supplementary list
- Each item: rank number (text-muted-foreground font-mono) + entity name as `<Link>` + count badge
- Link styling: `text-foreground hover:text-primary underline decoration-border underline-offset-2 hover:decoration-primary transition-colors`
- Count badge: `text-muted-foreground font-mono text-xs tabular-nums`

**Links target:**
- Designer items: `/designers/{designerId}`
- Genre items: no detail page exists, so genre names are plain text (not links)
- Status items: no list needed (donut chart is self-explanatory)
- Size items: no list needed (5 fixed categories are self-explanatory)

**Keyboard/a11y:** Standard `<Link>` elements, inherently keyboard-navigable and screen-reader accessible (D-11).

### 8. Overview Layout Composition

**Purpose:** Arranges all Phase 19 content within the existing `StatsPageShell` overview tab (D-14 through D-17).

**Layout order (top to bottom):**
1. `MetricsBar` -- full width
2. `LifetimeCounters` -- full width, `mt-8` (32px gap)
3. Collection charts 2x2 grid -- `mt-8` (32px gap)
   - Row 1: Status donut + Size bars
   - Row 2: Designer bars + Genre bars

**2x2 grid implementation:**
```
grid grid-cols-1 md:grid-cols-2 gap-4
```
Falls to single column below `md:` breakpoint (768px) (Claude's discretion on breakpoint).

**Each chart cell:** Wrapped in `Card` with `CardHeader` (heading) + `CardContent` (chart + optional ranked list).

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Chart tooltip (all charts) | shadcn `ChartTooltip` + `ChartTooltipContent` on hover -- shows label + count. Default Recharts behavior. |
| Designer name click | `<Link href="/designers/{id}">` navigates to designer detail page |

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Chart alt text | Each chart card has an `aria-label` on the chart container describing the data (e.g., "Bar chart showing project count by size category") |
| Ranked list links | Standard `<Link>` with visible text -- inherently accessible |
| No chart segment clicks | D-13 explicitly avoids onClick on chart segments to prevent WCAG keyboard accessibility issues |
| Color contrast | All text meets WCAG AA (4.5:1). Chart colors are supplementary to labels/tooltips, not sole information carriers. |
| Screen reader numbers | `font-variant-numeric: tabular-nums` is purely visual -- screen readers read the number value correctly |
| Section headings | Each chart card uses a heading element (h3) for document outline |
