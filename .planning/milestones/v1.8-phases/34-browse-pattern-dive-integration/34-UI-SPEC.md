## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, `gap-1` / `p-1` |
| sm | 8px | Compact element spacing, `gap-2` / `p-2`, filter bar gaps |
| md | 16px | Card grid gap, tab content padding-top (`pt-4`), `gap-4` |
| lg | 24px | Section spacing, `gap-6` / `space-y-6` |
| xl | 32px | Layout gaps, `gap-8` |
| 2xl | 48px | Empty state vertical padding, `py-12` |

Exceptions:
- Card padding: `p-5` (20px) inherited from Phase 32 SeriesCard DesignOS spec.
- Tab trigger min height: `min-h-11` (44px) inherited from existing PatternDiveTabs -- touch target for accessibility.
- Icon gap in tabs: `gap-1.5` (6px) inherited from existing PatternDiveTabs tab triggers.
- Chevron kerning: `ml-0.5` (2px) optical micro-adjustment on sort pill chevron icons -- inherited from Phase 32 sort pills.

**Executor guidance:** No new spacing values introduced. All values match existing patterns from PatternDiveTabs and SeriesList.

### CP-03: Series Tab Empty State

| Property | Value |
|----------|-------|
| Component | `<EmptyState>` with `heading={false}` (no `<h2>` -- tab content does not own page heading) |
| Icon | `Library` from lucide-react (D-07) |

| Layout | Centered, `py-12`, consistent with existing EmptyState component |

### CP-04: Browse Tab Series Filter (MultiSelectDropdown)

| Property | Value |
|----------|-------|
| Component | `<MultiSelectDropdown>` -- same as Status and Size filters (D-08) |
| Label | `"Series"` |
| Position in filter bar | After Size: Search input, Status, Size, **Series** (D-10) |
| Filter options source | Derived from `GalleryCardData[]` at render time: unique series from cards + synthetic "Unassigned" option (D-09, D-11) |
| "Unassigned" option | `{ value: "__unassigned__", label: "Unassigned" }` -- always present as the first option. Filters for cards where `seriesId` is `null`. (D-09) |
| Named series options | `{ value: series.id, label: series.name }` sorted alphabetically by name |
| URL state | `?series=id1,id2` via `parseAsArrayOf(parseAsString, ",")` in `useGalleryFilters` |
| Filter predicate | If filter includes `"__unassigned__"`, include cards where `seriesId === null`. If filter includes named series IDs, include cards where `seriesId` matches. If both, union. |

### CP-05: FilterChips Extension for Series

| Property | Value |

| Chip aria-label | `"Remove Series: {seriesName} filter"` |
| Clear all | `clearFilters` callback updated to also clear series filter |
| `hasActiveFilters` | Updated to include `seriesFilter.length > 0` |

### CP-06: GalleryCardData Extension

| Property | Value |
|----------|-------|
| New fields | `seriesId: string | null` and `seriesName: string | null` added to `GalleryCardData` interface |
| Data source | `chart.series?.id ?? null` and `chart.series?.name ?? null` from extended `getChartsForGallery()` query (D-11) |
| Query extension | Add `series: { select: { id: true, name: true } }` to Prisma include in `getChartsForGallery()` (D-11) |

## Visual Hierarchy

**Series tab:** The sort bar is the first element, followed by the card grid. No page-level heading within the tab content (the "Pattern Dive" heading and description are rendered by the parent page). The card grid is the primary visual anchor. Empty state centers vertically in the tab content area.

**Browse tab with series filter:** The Series dropdown sits at the end of the filter bar row, visually equal to Status and Size dropdowns. When active, it shows a count badge in the trigger and adds filter chips below. No visual priority over other filters.

## Accessibility Contract

| Requirement | ARIA Pattern | Test Approach |
|-------------|-------------|---------------|
| Series tab keyboard activation | Tab trigger is a `<button>` within `TabsList` -- standard `role="tab"` from shadcn Tabs | Tab to trigger, Enter/Space activates |
| Series tab label | `aria-label="Series"` on TabsTrigger (consistent with existing tabs) | Verify screen reader announces "Series" |
| Series cards clickability | `<Link>` wrapping full card, inherits accessible name from series name | Verify card renders as `<a>` with href containing series ID |
| Sort pills keyboard | `type="button"` on all sort buttons, visible label is the accessible name | Tab to pills, Enter/Space toggles sort |
| Series filter dropdown | `aria-haspopup="listbox"`, `aria-expanded`, `aria-controls` (inherited from MultiSelectDropdown) | Verify keyboard navigation: ArrowDown/Up, Enter/Space to toggle, Escape to close |
| Unassigned filter option | `role="option"` with `aria-selected` (inherited from MultiSelectDropdown) | Verify "Unassigned" option is toggleable via keyboard |
| Filter chips removable | `aria-label="Remove Series: {name} filter"` on chip dismiss button | Verify screen reader announces removal action |
| Empty state | EmptyState renders text content accessible to screen readers, link to /series is focusable | Verify link receives focus via Tab |
