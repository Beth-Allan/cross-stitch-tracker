## Milestone Summary

**Key Decisions:**
- Status colors as CSS custom properties (not Tailwind config or JS constants) — consumed via var() in STATUS_CONFIG
- Supply stitch total is display-only hint, never auto-overrides manual field
- Library-wide insights (not session-gated) — any chart in collection contributes to stats
- StatusFilterPills with shallow:false for server re-render (not client-side filter)
- R2 orphan cleanup scoped to session photos + chart covers only (not thumbnails)
- CalculatorCard uses optimistic state with server action persistence

**Issues Resolved:**
- Designer quick-add broken (dialog not wired in chart form)
- Tab-to-type not working on SearchableSelect instances
- Designer detail showing wrong/missing thumbnails
- Stats insights empty without session data
- Chart axes showing decimal values for discrete data
- Days-in-library displaying duplicated numbers
- Status/size badges all grey
- File upload limited to 10MB, no zip support
- Silent error patterns masking failures
- R2 photo orphans on replacement

**Issues Deferred:**

- InlineDesignerDialog controlled-only simplification (999.75)
- SuppliesTab co-dependent props grouping (999.76)
- Server action test coverage for updateProjectSettings (999.79)
