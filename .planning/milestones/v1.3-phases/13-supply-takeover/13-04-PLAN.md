  <action>
**Gap 1 fix -- Activity to conditional rendering (lines ~631-663):**

Replace the supply-mode `<Activity mode={mode === "supply" ? "visible" : "hidden"}>` wrapper with a simple conditional `{mode === "supply" && (...)}`. The form-mode Activity on line ~351 can stay -- it starts visible so Popover init is not deferred.

Root cause: React 19 Activity with `mode="hidden"` defers Base UI Popover internal FloatingRootContext init to OffscreenLane. When Activity becomes visible, PopoverTrigger has stale empty context -- clicks do nothing. Conditional rendering avoids this entirely because the CalculatorCard mounts fresh when supply mode activates.

Note: Conditional rendering means CalculatorCard remounts on each mode switch. This is fine because calcParams state lives in the parent (chart-merged-form), not in CalculatorCard. The CalculatorCard is a controlled component receiving calcParams as a prop.

**Gap 4 fix -- Draft auto-save on unmount:**

Add a `useEffect` cleanup in chart-merged-form.tsx that calls `saveDraftV2` when the component unmounts (if the form was not submitted). Use refs to avoid stale closures:

1. Add a `submittedRef = useRef(false)` -- set to `true` in `onSuccess` callback (before `clearDraft()` and `router.push`).
2. Add refs for form values, supply rows, and calcParams that update on every render (or use a single combined ref).
3. Add a `useEffect(() => { return () => { if (!submittedRef.current && formValuesRef.current.name) { saveDraftV2(formValuesRef.current, supplyRowsRef.current, calcParamsRef.current); } }; }, [])` -- empty deps so it only fires on unmount.
4. Import `saveDraftV2` from `use-draft-persistence` (already imported in the file as part of `handleSaveDraft`).

This handles both client-side Next.js Link navigations (which trigger unmount but NOT beforeunload) and full-page navigations.

Add tests:
- Test: component unmount triggers saveDraftV2 call when form has content
- Test: component unmount does NOT save draft when form was submitted (submittedRef is true)
- Test: component unmount does NOT save draft when form name is empty
