## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, button gap |
| md | 16px | Default element spacing, field group gap |
| lg | 24px | Section padding, form group internal spacing |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Page top/bottom padding |
| 3xl | 64px | Not used this phase |

Exceptions: 44px min touch target on kebab menu trigger (matches HeroKebabMenu pattern)

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (normal) | 1.5 |
| Label | 14px (text-sm) | 400 (normal) | 1.4 |
| Heading | 24px (text-2xl) | 600 (semibold) | 1.2 |
| Caption | 12px (text-xs) | 400 (normal) | 1.5 |

Notes: Heading uses `font-heading` (Fraunces). All other text uses `font-body` (Source Sans 3). Matches existing page-title pattern. Labels differentiate from body text via `text-muted-foreground` color rather than font weight.

## Color

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | bg-background (stone-50) | Page background |
| Secondary (30%) | bg-card (white) | Form surface, table rows, sticky save bar |
| Accent (10%) | text-primary / bg-primary (emerald-600) | Save Changes button, required field dots, focus rings, "Manage Supplies" link |
| Destructive | text-destructive / bg-destructive (red-600) | Delete menu item, delete confirmation button |
| Muted | text-muted-foreground (stone-500) | Hint text, timestamps, disabled state text, field labels |

Accent reserved for:
- Primary CTA button ("Save Changes")
- Required field green dots (6px)
- Input focus ring (ring-ring)
- "Go to Supplies" link text
- Active nav indicators

---

## Focal Point

Primary focal point: page heading ("Edit [Chart Name]") + sticky save bar CTA ("Save Changes"). The heading anchors the user's context (what am I editing), while the persistent save bar provides constant action affordance.

## Interaction Contracts

### Edit Form (EDIT-01)

| Aspect | Contract |
|--------|----------|
| Layout | Identical to creation form: 720px max-width, single column, same field groups with dividers |
| Pre-population | All fields filled from existing chart/project data on load |
| Required fields | Same as creation: Chart Name, Status (green dot indicator) |
| Draft persistence | Disabled in edit mode (editing real data, not a draft) |
| Supply section | Replaced by ManageSuppliesLink (no milestone marker, no supply takeover) |
| Unsaved changes guard | `window.confirm("You have unsaved changes. Leave anyway?")` on navigation |
| Save action | Calls `updateChart` server action via `useChartForm` |
| After save | `router.push(/charts/[chartId])` + `toast.success("Changes saved")` |
| Back navigation | "Back to project" link at top (ArrowLeft icon + text) pointing to `/charts/[chartId]` |

### ManageSuppliesLink (D-01, D-02, D-03)

| Aspect | Contract |
|--------|----------|
| Position | Same DOM slot as milestone marker in creation flow (after the last field group) |
| Visual | Subtle card-style container (border-border, rounded-lg, p-4) with text + link |
| Copy | "Supplies are managed on the project page" |
| Link text | "Go to Supplies" (text-primary, underline-on-hover) |
| Link target | `/charts/[chartId]?tab=supplies` |
| Icon | ArrowRight (lucide) at 16px, inline after link text |

### ListRowKebabMenu (D-07, D-10)

| Aspect | Contract |
|--------|----------|
| Trigger | MoreHorizontal icon (20px), 44px min touch target, same styling as HeroKebabMenu trigger |
| Visibility | Desktop: opacity-40 on row, opacity-100 on hover/focus-within. Mobile card: always visible |
| Menu width | w-48 (matches HeroKebabMenu) |
| Items | "Edit Project" (Pencil icon, navigates to `/charts/[id]/edit`) + "Delete Project" (Trash2 icon, variant destructive, opens confirm dialog) |
| Align | align="end", sideOffset={8} |
| Delete confirmation | Reuses existing dialog pattern from chart-list.tsx (DialogTitle + DialogDescription + Cancel/Delete buttons) |

### StickySaveBar (edit mode adaptation)

| Aspect | Contract |
|--------|----------|
| Primary CTA | "Save Changes" (default variant Button) / "Saving..." while pending |
| Secondary CTA | Hidden in edit mode (no "Save Draft" — editing real data) |
| Hint text | "Ready to save at any point" (when chart name present) / "Enter a chart name to enable saving" (when empty) |
| Disabled state | Primary button disabled when chartName is empty or isSubmitting is true |

### Navigation Entry Points (D-07, D-08, D-09)

| Entry Point | Behavior |
|-------------|----------|
| Project detail hero Edit button | Already exists (`LinkButton href="/charts/[id]/edit"`). No changes. |
| List-row kebab "Edit Project" | `router.push(/charts/[id]/edit)` |
| Gallery card grid | No kebab menu (D-08). Click card -> project detail -> Edit button. |

## States

### Edit Form States

| State | Visual |
|-------|--------|
| Loading | Server component fetches data; no skeleton needed (page renders with data) |
| Idle | Form filled with current values, Save Changes enabled |
| Dirty | Same as idle (no visual diff indicator — save bar always present) |
| Submitting | "Saving..." on button, disabled state |
| Success | Redirect to project detail + toast |
| Validation error | Field-level red border + error message (existing FormField pattern) |
| Not found | 404 page (existing Next.js not-found) |
| Unsaved navigation | Browser confirm dialog |

### Kebab Menu States

| State | Visual |
|-------|--------|
| Row default (desktop) | Kebab trigger at opacity-40 |
| Row hover/focus | Kebab trigger at opacity-100 |
| Menu open | DropdownMenuContent visible, trigger focused |
| Delete pending | "Deleting..." text in dialog button, all dialog buttons disabled |

## Accessibility

| Concern | Implementation |
|---------|----------------|
| Kebab trigger | `aria-label="Project actions"` on DropdownMenuTrigger |
| Edit button (hero) | Existing LinkButton with visible "Edit" text |
| Delete dialog | Focus trap via Dialog component, `autoFocus` on Cancel button |
| Form labels | All inputs labeled via FormField component (existing) |
| Required indicator | Green dot is decorative (`aria-hidden`); actual requirement enforced by validation |
| Sticky save bar | `role="toolbar"` + `aria-label="Form actions"` (existing) |
