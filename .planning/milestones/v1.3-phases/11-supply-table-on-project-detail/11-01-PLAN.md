Build the ServerActionAdapter that bridges the SupplyTableAdapter interface to existing supply server actions, and extend the Result type to carry new junction IDs for animation wiring.

Purpose: This adapter is the persistence layer for the unified supply table on project detail. Output: ServerActionAdapter class with full test coverage, extended Result type, updated barrel exports.
