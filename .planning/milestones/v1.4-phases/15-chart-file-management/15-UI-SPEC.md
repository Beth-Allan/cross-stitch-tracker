## Interaction Contracts

### File List (Project Detail Overview Tab)

**Layout:** Vertical stack of file rows inside an InfoCard, placed directly below the Kitting Checklist card (32px gap). Section heading: "Working Copies" with Lucide `Files` icon.

**File row structure:**
```
[FileTypeIcon 16x16] [filename truncated] [file size] [download icon-button] [delete icon-button]
```

- Row height: 40px (min-h-10) with 8px vertical padding
- Row has `hover:bg-muted` feedback
- Clicking filename/row area opens file in new tab (PDFs) or triggers download (others)
- Download icon-button: `Download` (Lucide), 32x32 touch target
- Delete icon-button: `Trash2` (Lucide), 32x32 touch target, text-muted-foreground, hover:text-destructive
- Rows separated by 1px border-border dividers
- Newest files appear first (chronological descending by createdAt)

**File type icons (FileTypeIcon component):**

| MIME / Extension | Icon | Color |
|------------------|------|-------|
| application/pdf | `FileText` | text-red-500 |
| image/* | `Image` | text-blue-500 |
| .pat (PCStitch) | `FileCode` | text-purple-500 |
| .xsd (Pattern Maker) | `FileCode` | text-purple-500 |
| .css (CrossStitch) | `FileCode` | text-purple-500 |
| .saga (Saga) | `FileCode` | text-purple-500 |
| Unknown/fallback | `File` | text-muted-foreground |

### Upload (Multi-File)

**In chart creation form:** Multi-file input with `multiple` attribute. Upload button labeled "Upload Working Copies". After selecting files, each file shows as a row with progress.

**On project detail page:** "Add Files" button (variant="outline", size="sm") positioned at top-right of the file list section heading row.

**Upload progress per file:**
- Indeterminate spinner (Loader2 animate-spin) next to filename while uploading
- On success: row transitions to standard file row appearance
- On error: row shows destructive text below filename, "Retry" link

**Upload validation feedback:**
- Invalid file type: inline error below the upload area — "Unsupported file type. Accepted: PDF, images, .pat, .xsd, .css, .saga"
- File too large: inline error — "File exceeds 10MB limit."
- Upload failure: inline error — "Upload failed. Please try again."

### Delete Confirmation

**Trigger:** Trash2 icon-button on file row
**Dialog pattern:** Reuses existing `DeleteConfirmationDialog` structure
- Title: "Remove Working Copy"
- Body: "This will permanently delete "{filename}" from this chart. This action cannot be undone."
- Cancel button: variant="outline"
- Confirm button: variant="destructive", label: "Delete File"
- Pending state: "Deleting..." with disabled buttons

### Kitting Checklist Integration

**Current pattern (to update):**
```
[Check/X icon] Digital Copy — Ready / Not uploaded
```

**New pattern:**
```
[Check/X icon] Digital Copy — N files attached / Not uploaded
```

- Check icon (green) when fileCount > 0
- X icon (muted) when fileCount === 0
- Detail text: "{N} file{s} attached" when files exist, "Not uploaded" when empty

### Empty State (No Files)

**Component:** `EmptyState` with:
- Icon: `Files` (Lucide)
- Heading: "No working copies yet"
- Description: "Upload your digital pattern files — PDFs, images, or cross-stitch software files."
- CTA: Button (variant="outline") — "Upload Files"

| Breakpoint | Behavior |
|------------|----------|
| Mobile (<640px) | File rows stack filename above metadata (size + actions). Icon buttons remain visible. Full-width upload button. |
| Tablet/Desktop (>=640px) | Single-line file rows: icon + filename + size + actions inline. "Add Files" button in section header. |

## Accessibility

| Element | Requirement |
|---------|-------------|
| File row | `role="link"` or `<a>` wrapping the clickable area, `aria-label` includes full filename |
| Download button | `aria-label="Download {filename}"` |
| Delete button | `aria-label="Delete {filename}"` |
| Upload input | `aria-label="Upload working copy files"`, hidden input with visible button trigger |
| File type icon | `aria-hidden="true"` (decorative) |
| Delete dialog | Focus trapped, returns focus to trigger on close |
| Upload progress | `aria-live="polite"` region announces completion/error |
