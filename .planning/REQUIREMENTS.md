# Requirements: Cross Stitch Tracker

**Defined:** 2026-05-16
**Core Value:** A stitcher can manage their entire chart collection and supplies faster and more pleasantly than Notion, with comprehensive statistics that make tracking feel rewarding.

## v1.4 Requirements

Requirements for Fixes & Polish milestone. Each maps to roadmap phases.

### Chart Files

- [ ] **FILE-01**: User can attach multiple digital working copy files to a single chart
- [ ] **FILE-02**: User can add/remove individual working copy files without affecting others
- [ ] **FILE-03**: User can see all attached working copies listed on the project detail page

### Input

- [ ] **INPUT-01**: User can type supply codes quickly without dropped keystrokes in SearchToAdd

### Dashboard

- [ ] **DASH-01**: Spotlight "Rediscover This One" section displays at a constrained, appropriate size
- [ ] **DASH-02**: "Check it Out" and "Shuffle Spotlight" buttons display at matching sizes

### Images

- [ ] **IMG-01**: User can set a focal point on cover images to control which area is displayed when cropped
- [ ] **IMG-02**: Focal point is respected across all image display contexts (gallery cards, dashboard, hero banners, project detail)

## Future Requirements

Deferred to subsequent milestones. See PROJECT.md Deferred section.

### Statistics & Achievements (v1.5+)

- **STAT-01**: Comprehensive statistics engine (daily/weekly/monthly/yearly metrics)
- **STAT-02**: Monthly stitch bar charts and stitching calendar view
- **STAT-03**: Year in Review tab with 8 stat sections and year selector
- **STAT-04**: Personal bests (most stitches in a day, longest streak, records)
- **ACHV-01**: Achievement trophy case with auto-tracked milestones, streaks, and records

### Goals & Planning (v1.6+)

- **GOAL-01**: Goal tracking (project-specific and global, milestone targets, frequency goals)
- **PLAN-01**: Scheduling plans (project start dates, recurring stitching days, seasonal focus)
- **ROT-01**: Multi-style rotation management (Focus+Rotate, Milestone, Daily, Round Robin, Random, Seasonal)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Full image cropping/editing UI | Focal point is simpler and sufficient; crop tools add complexity |
| Bulk file upload for working copies | Single file add/remove is the core need for v1.4 |
| SearchToAdd architectural rewrite | Fix the keystroke bug specifically; broader refactor deferred |
| Dashboard layout redesign | Only fixing Spotlight sizing and button consistency |
