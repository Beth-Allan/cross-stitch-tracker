# Phase 21 -- UI Design Contract

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 | Table cells, insight list items, estimate descriptions |
| Label | 11px (`text-xs`) | 600 (semibold) | 1.5 | Uppercase section sub-labels, unit labels ("days", "stitches") |
| Heading | 14px (`text-sm`) | 600 (semibold) | 1.2 | Section headings with `font-heading` (Fraunces) |
| Display | 24px (`text-2xl`) | 600 (semibold) | 1.2 | Record values in All-time column, hero numbers. `font-mono tabular-nums` |

Notes:
- Record values in year columns use 16px (`text-base`) mono semibold, not 24px (reserve 24px for All-time emphasis per D-04)
- Progress percentages use 12px (`text-xs`) mono semibold
- Toast record value uses 16px body weight 600

## Color

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-background` (stone-50) | Page background, tab content area |
| Secondary (30%) | `bg-card` (white) | Records table card, insight cards, estimate cards |

### Accent reserved for (emerald-600 / success tokens):

- Section heading icons (Trophy, Palette, Users, Target)
- All-time column background highlight (`bg-success-muted` with `border-success-border`)
- Progress bar fill in completion estimates (`bg-progress`)
- Clickable entity links on hover (`hover:text-primary`)
- Year scope segmented control active state (`bg-selected`, `text-selected-foreground`, `border-selected-border`)

### Celebration color usage (amber / warning tokens):

- Trophy icon in celebration toast: `text-warning` (amber-600)
- Toast background: `bg-warning-muted` (amber-50) with `border-warning-border` (amber-200)
- Confetti particle colors: emerald-400, amber-400, amber-500 (gold tones), emerald-300

### Thread swatch colors:

- Use `ThreadColor.hexCode` as inline `backgroundColor` style
- Missing hex fallback: `bg-muted` (stone-100) with `border-border` (stone-300) -- 16x16px rounded square

## Layout Contract

### RecordsOverview -- Single Scrollable Page

```
[YearScopeToggle: All-time | 2026 | 2025 | ...]     (sticky top, right-aligned)
                                                       
[Card: Records Table]                                  (full width)
  [Personal Bests section: 4 rows]
  [Grouped divider: "Fastest Completions"]
  [Fastest Completions section: 5 rows]

[Section gap: 32px]

[Grid: 1-col mobile / 3-col desktop]
  [Card: Top Thread Colors]     (10 items max)
  [Card: Designer Completion]   (10 items max)
  [Card: Most Stitched Genres]  (10 items max)

[Section gap: 32px]

[Card: Completion Estimates]                           (full width)
  [List of active projects with progress bars, sorted by soonest completion]
```

### Records Table -- Responsive Behavior

- **Desktop (>= 768px):** Full table with columns: Record Type | All-time | 2026 | 2025 | ...
- **Mobile (< 768px):** Horizontal scroll within the Card container (leverages existing `Table` component's `overflow-x-auto` wrapper). No stacked layout -- table data is inherently columnar and stacking loses the year-comparison value.

### Year Scope Toggle

- Segmented control using button group (not tabs -- visual differentiation from StatsPageShell tabs)
- Options: "All-time" + detected years in descending order (e.g., 2026, 2025)
- Active state: `bg-selected text-selected-foreground border-selected-border rounded-lg`
- Inactive state: `text-muted-foreground hover:text-foreground`
- Container: `bg-muted rounded-xl p-1` pill background
- Position: right-aligned above the records table, `mb-4`
- URL state: `nuqs` with `parseAsString` key `"scope"`, default `"all"`

### Insights Grid

- **Desktop (>= 1024px):** 3-column grid (`grid-cols-1 lg:grid-cols-3 gap-4`)
- **Tablet (>= 768px):** 2-column grid, genre card spans full on odd count
- **Mobile:** Single column stack

## Celebration System Detail (REC-03)

### Record Detection Flow

1. `createSession` server action inserts session
2. Post-insert: run comparison queries (best day, best session, streak)
3. Return extended response: `{ success: true, data: session, brokenRecords: BrokenRecord[] }`
4. Client checks `brokenRecords.length > 0`

### BrokenRecord Type

```ts
interface BrokenRecord {
  type: "bestDay" | "bestSession" | "longestStreak";
  label: string;        // "Best Day" | "Best Session" | "Longest Streak"
  oldValue: number;
  newValue: number;
  unit: string;         // "stitches" | "days"
}
```

### Confetti Burst

- Trigger: `canvas-confetti` from `{ origin: { x: 0.5, y: 0.3 } }` (center-top)
- Duration: ~1.5 seconds, `particleCount: 120`, `spread: 80`, `startVelocity: 45`
- Colors: `["#34d399", "#fbbf24", "#f59e0b", "#6ee7b7"]` (emerald-400, amber-400, amber-500, emerald-300)
- Gravity: default (1), ticks: 100
- Multiple records: fire confetti once per broken record with 500ms stagger

### Celebration Toast

- Library: sonner (already installed, configured at `position="bottom-right"`)
- Use `toast.custom()` for themed rendering (not `toast.success()` -- needs amber not emerald)
- Duration: 5000ms (auto-dismiss)
- Layout:

```
[Trophy icon (amber)]  New Record!                     [x close]
                       Best Day: 1,247 stitches
                       Previous: 982
```

- Container: `bg-warning-muted border border-warning-border rounded-xl p-4`
- "New Record!" heading: `text-sm font-heading font-semibold text-foreground`
- Trophy icon: `Trophy` from lucide, `text-warning h-5 w-5`
- Record type + value: `text-sm text-foreground` with value in `font-mono font-semibold`
- Previous value: `text-xs text-muted-foreground`
- Multiple records: stacked toasts (sonner handles stacking natively)

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Records table | Standard `<table>` semantics. Screen reader announces column headers. |
| Year scope toggle | `role="group"` with `aria-label="Time scope"`. Each button has `aria-pressed` for active state. |
| Entity links | Standard `<Link>` with visible underline. No `aria-label` needed -- text is descriptive. |
| Color swatches | Decorative only. Thread name provides the text alternative. `aria-hidden="true"` on swatch `<div>`. |
| Celebration toast | sonner toasts have built-in `role="status"` and `aria-live="polite"`. |
| Confetti | Pure visual decoration. Canvas element is `aria-hidden="true"`. |
| Progress bars | `role="progressbar"` with `aria-valuenow`, `aria-valuemin="0"`, `aria-valuemax="100"`, `aria-label="{project name} completion"`. |
| Empty states | Standard EmptyState component with descriptive text. |
