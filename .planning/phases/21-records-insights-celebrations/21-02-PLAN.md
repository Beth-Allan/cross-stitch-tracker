| Boundary | Description |

| URL -> page.tsx | scope param from URL parsed via nuqs, used to select data scope |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-04 | Tampering | YearScopeToggle URL param | mitigate | nuqs parseAsString validates to string. Queries parse to integer with fallback to "all" on NaN. Invalid scope values produce empty/all-time results, not errors. |
| T-21-05 | Information Disclosure | Entity links in RecordsTable | accept | Links go to /charts/{chartId} which has its own auth check. No data leakage from the link URL itself. |
| T-21-06 | Denial of Service | Promise.all with 17 queries | mitigate | All queries are cached via unstable_cache. First load may be slow but subsequent loads are fast. Promise.all fails fast on error — page shows Next.js error boundary. |
</threat_model>
