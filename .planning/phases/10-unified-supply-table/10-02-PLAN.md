<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> PortalAutocomplete | Search text from user drives adapter.searchSupplies calls |
| User input -> InlineCreateDialog | Name/code from user passed to adapter.createSupply |
| Portal -> document.body | createPortal renders outside React tree into document.body |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-04 | Spoofing | PortalAutocomplete | accept | Search results come from adapter (local-state in Phase 10); React auto-escapes all JSX output |
| T-10-05 | Tampering | InlineCreateDialog | mitigate | Validate name with trim().min(1) before calling onSubmit; do not pass raw user input to adapter |
| T-10-06 | Denial of Service | PortalAutocomplete | mitigate | Parent component debounces search at 150ms; max 8 items rendered; dropdown only open when input focused |
| T-10-07 | Information Disclosure | PortalAutocomplete | accept | Shows supply catalog data (colors, codes) that is non-sensitive application data |
</threat_model>
