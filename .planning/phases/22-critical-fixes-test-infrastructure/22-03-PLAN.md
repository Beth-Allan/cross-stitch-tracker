<objective>
Make the stats page resilient to individual query failures by switching from Promise.all to Promise.allSettled.

Purpose: The stats page currently runs 17 parallel queries in a single Promise.all. If ANY query fails (DB timeout, cache miss, transient error), the entire page crashes. With Promise.allSettled, each query result becomes nullable and components render graceful "unavailable" fallbacks for failed sections while showing all successful data.

Output: settled() utility, stats page.tsx using Promise.allSettled, 3 tab components handling nullable props.

**Step 1: Create settled() utility** (per D-02).

Create `src/lib/utils/settled.ts`:
```typescript
/**
 * Extracts the value from a PromiseSettledResult.
 * Returns null for rejected results, enabling graceful degradation.
 */
export function settled<T>(result: PromiseSettledResult<T>): T | null {
  return result.status === "fulfilled" ? result.value : null;
}
```

Create `src/lib/utils/settled.test.ts`:
```typescript
import { describe, it, expect } from "vitest";
import { settled } from "./settled";

describe("settled", () => {
  it("returns value for fulfilled result", () => {
    const result: PromiseSettledResult<number> = { status: "fulfilled", value: 42 };
    expect(settled(result)).toBe(42);
  });

  it("returns null for rejected result", () => {
    const result: PromiseSettledResult<number> = { status: "rejected", reason: new Error("fail") };
    expect(settled(result)).toBeNull();
  });

  it("preserves complex types", () => {
    const data = { id: "1", name: "test" };
    const result: PromiseSettledResult<typeof data> = { status: "fulfilled", value: data };
    expect(settled(result)).toEqual(data);
  });
});
```
