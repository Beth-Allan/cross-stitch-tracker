<objective>
Wire the CalculatorCard component into the project detail Supplies tab with database persistence, and fix the supply sort bug (BUG-03).

Purpose: Users currently cannot adjust skein calculation parameters (fabric count, strand count, over 1/2, waste %) from the project detail page -- they must go to the edit form. Adding the CalculatorCard here makes supply management self-contained on the detail page. The sort bug prevents users from organizing their supply list.

Output: CalculatorCard rendered above the supply table on project detail Supplies tab, with optimistic persistence via updateProjectSettings. Fabric options fetched and passed through the component hierarchy. Supply sort controls working correctly.
</objective>
