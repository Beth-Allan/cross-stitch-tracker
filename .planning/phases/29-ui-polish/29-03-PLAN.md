<objective>
Increase the file upload size limit from 10MB to 50MB and add .zip support for chart file uploads.

Purpose: Users need to upload larger pattern PDFs (some are 15-40MB) and zipped pattern bundles as digital working copies. The current 10MB limit and lack of zip support block legitimate use cases. R2 supports up to 5GB per object, so 50MB is well within platform limits.

Output: MAX_FILE_SIZE updated to 50MB with matching error message, zip MIME types added to ALLOWED_FILE_TYPES and ALLOWED_CHART_FILE_TYPES, .zip added to ALLOWED_CHART_FILE_EXTENSIONS. Covers and session photos remain image-only (ALLOWED_IMAGE_TYPES unchanged).
</objective>
