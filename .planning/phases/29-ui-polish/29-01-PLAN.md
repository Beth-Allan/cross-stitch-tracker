<objective>
Color the status and size badges on gallery cards and grid views, and add a digital copy indicator to gallery cards.

Purpose: Gallery cards currently show grey pills for Unstarted status and all size categories. This makes the gallery visually flat and loses information density. Colored badges make status and size scannable at a glance across 500+ charts. The digital copy indicator lets users know which charts have uploaded pattern files without opening the detail page.

Output: Updated STATUS_CONFIG (UNSTARTED = slate), updated SIZE_COLORS (-100 to -50 shades), colored size badges on gallery card/list/table views, hasDigitalCopy field in gallery data pipeline, FileText icon + label in gallery card body.
</objective>
