<objective>
Refactor LocationRow and AppRow to use the stretched link pattern, eliminating nested interactive element ARIA violations (per POLISH-01 / backlog 999.0.19).

Purpose: Both components currently use `<div role="button">` containing child `<button>` elements, which is invalid ARIA (nested interactive elements). The stretched link pattern replaces this with a `<Link>` element stretched to fill the card via absolute positioning, with edit/delete buttons layered above via z-index. This produces valid, accessible markup where screen readers see a link and buttons as siblings.

Output: Two refactored components with valid ARIA, matching tests, identical visual appearance.
</objective>
