### Component Specifications

#### SummaryBar

**Purpose:** Collapsed form representation during supply takeover mode

**Layout:**
```
[sticky top-14 z-90]
+--------------------------------------------------+
| <- Details   Chart Name . Designer . Status . 54,800 stitches |
+--------------------------------------------------+
```

**Visual spec:**
- Position: `sticky top-14 z-[90]` (below top-bar h-14, above content, below sticky save bar z-100)
- Background: `bg-card`
- Border: `border-b border-border`
- Padding: `py-3 px-4` inside a `max-w-[720px] mx-auto` wrapper
- Layout: `flex items-center gap-3`
- "Details" link: `text-primary text-sm font-medium hover:underline`, with ArrowLeft icon (size-4)
- Token text: `text-sm text-foreground` for values, dot separator `text-muted-foreground mx-1`

**Data binding:** Live from `form.values` (D-14). Tokens built as `[name, designerName, statusLabel, stitchCountFormatted].filter(Boolean).join(" . ")`. Chart name and status always present (D-16).

**Interaction:**
- "Details" click toggles Activity mode back to form view
- No scroll reset on toggle (Activity preserves position)
- No loading state on toggle (instant, D-01)

**Accessibility:**
- `role="banner"` with `aria-label="Project summary"`
- "Details" link: `aria-label="Return to form details"`

#### CalculatorCard

**Purpose:** Fabric assignment + skein calculator parameter configuration

**Layout:**
```
+--------------------------------------------------+
| Skein Calculator                                   |
|                                                    |
| Fabric    [SearchableSelect dropdown ............] |
|                                                    |
| STRANDS   [2]    OVER  [1] [2]    WASTE  [20%]   |
+--------------------------------------------------+
```

**Visual spec:**
- Container: `bg-card border border-border rounded-lg p-4` (styled card, NOT flat settings bar per D-13)
- Title: `text-sm font-semibold text-foreground mb-3` -- "Skein Calculator"
- Fabric row: `mb-3` with SearchableSelect spanning full width
- Controls row: `flex flex-wrap gap-x-6 gap-y-3`
- Each control group: `flex items-center gap-2`
- Control labels: `text-muted-foreground text-[11px] font-semibold tracking-wider uppercase`
- Over buttons: min-h-8 min-w-8, rounded, active uses `bg-primary text-primary-foreground`, inactive uses `bg-muted text-foreground hover:bg-accent`
- Strands and Waste: reuse `EditableNumber` component pattern from existing CalculatorSettingsBar

**Data binding:**
- Fabric selection syncs with `form.values.fabricId` (D-11)
- Fabric selection auto-fills `fabricCount` in CalcParams (D-10), value remains editable after
- Fabric dropdown shows unassigned fabrics from `unassignedFabrics` prop (D-12)
- CalcParams start at `DEFAULT_CALC_PARAMS` and are stored in component state (not persisted until final save)
- Fabric display: show `{count}ct ({fabricName})` when linked, `{count}ct (default)` when not

**Interaction:**
- Fabric selection: SearchableSelect dropdown with search
- Strands: EditableNumber, min 1 max 6
- Over: two-button segmented control (1 / 2)
- Waste: EditableNumber with `%` suffix, min 0 max 50

**Accessibility:**
- Card: `role="group" aria-label="Skein calculator settings"`
- Over buttons: `aria-pressed` for active state, `aria-label="Stitch over N threads"`

### Mode Transition (Activity Toggle)

**Mechanism:** React `<Activity>` (stable in React 19.2.5) wrapping form and supply sections. Two Activity regions: form (mode="form") and supply (mode="supply"). Only one visible at a time.

**Trigger (form -> supply):**
- Milestone marker "Add supplies" button click
- Currently: creates chart then redirects. Phase 13 replaces with mode state toggle
- Button disabled when `!form.values.name` (chart name required)

**Trigger (supply -> form):**
- "Details" link in SummaryBar
- Toggles mode state back to "form"

**Transition behavior:**
- Instant -- no loading spinner, no animation delay (per specifics)
- Form state preserved by Activity (no unmount)
- Supply state preserved by Activity (no unmount)
- No scroll reset on toggle
- Focus management: on transition to supply mode, focus moves to fabric dropdown in calculator card. On return to form, focus moves to the field that was last focused (or chart name if unknown)

**Page structure in supply mode:**
```
[TopBar - h-14, fixed top-0]
[SummaryBar - sticky top-14 z-90]
[CalculatorCard - in flow, max-w-[720px] mx-auto px-5]
[SupplyTable - in flow, max-w-[720px] mx-auto px-5]
[StickySaveBar - fixed bottom-0 z-100]
```

## Interaction States

### Supply Mode Toggle

| State | Visual |
|-------|--------|
| Form mode (default) | Form visible, milestone marker at bottom. No summary bar. No calculator card. |
| Supply mode | Form hidden (Activity). Summary bar sticky at top. Calculator card + supply table fill page. |
| Transitioning | Instant -- no intermediate state |

### Calculator Card

| State | Visual |
|-------|--------|
| No fabric selected | Dropdown shows placeholder "Select fabric...", fabricCount uses default (14) |
| Fabric selected | Dropdown shows fabric name, fabricCount auto-populated from fabric.count |
| Fabric overridden | EditableNumber for fabricCount shows user-entered value, fabric label still shows linked fabric |

### Supply Table (in creation flow)

| State | Visual |
|-------|--------|
| Empty | Empty state message below section dividers. Add row visible at top. |
| Has rows | Grouped sections with data rows. Same visual as project detail supply table. |
| Adding row | Same keyboard flow as Phase 10/11 -- type code, autocomplete, Enter, qty, Enter |

### StickySaveBar

| State | Visual |
|-------|--------|
| No chart name | Save Draft + Create disabled. Hint: "Enter a chart name to enable saving" |
| Chart name entered | Save Draft + Create enabled. Hint: "Ready to save at any point" |
| Creating | Create button shows "Creating...", disabled. Save Draft disabled. |
