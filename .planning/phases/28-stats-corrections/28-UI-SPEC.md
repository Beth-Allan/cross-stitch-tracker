## StatusFilterPills Specification

**Visual pattern:** Identical to existing `YearScopeToggle` -- inline pill row with `bg-muted rounded-xl p-1` container, gap-1 between pills.

**State management:** nuqs `useQueryStates` with `parseAsArrayOf(parseAsStringLiteral(...))` for multi-select. Parameter name: `status` (array).

**Pill labels and groups:**

| Pill Label | Status Values Included | Default |
|------------|----------------------|---------|
| All | (no filter -- full library) | Active when no pills selected |
| Not Started | `UNSTARTED` | Inactive |
| In Progress | `KITTING`, `KITTED`, `IN_PROGRESS`, `ON_HOLD` | Inactive |
| Complete | `FINISHED`, `FFO` | Inactive |

**Interaction:**
- Clicking a group pill toggles it on/off (multi-select)
- When any group pill is active, "All" pill deactivates
- When all group pills are deactivated, "All" reactivates automatically
- "All" pill click clears all group pill selections

**Styling (matches YearScopeToggle exactly):**
- Active pill: `bg-selected text-selected-foreground border-selected-border rounded-lg border px-3 py-1.5 text-sm font-medium shadow-sm`
- Inactive pill: `text-muted-foreground hover:text-foreground rounded-lg px-3 py-1.5 text-sm font-medium`

**Accessibility:**
- Container: `role="group" aria-label="Filter by status"`
- Each pill: `aria-pressed={isActive}` (toggle button pattern)
- All pills: `type="button"`

**Placement:** Above the 2-column insights grid on the Overview tab, right-aligned (`flex justify-end`).

## Days-in-Library Fix (Dashboard)

**Current (broken):**
```
23
23 days in library
```

**Fixed:**
```
23
days in library
```

**Implementation:** `formatAge()` changes from returning `"23 days"` to returning `"days"` / `"months"` / `"years"` (unit only). The number is already rendered separately by the template.

**Thresholds (unchanged):**
- < 30 days: unit = "days"
- < 365 days: unit = "months"
- >= 365 days: unit = "years"

**Label line format:** `{unit} in library` (e.g., "days in library", "months in library")
