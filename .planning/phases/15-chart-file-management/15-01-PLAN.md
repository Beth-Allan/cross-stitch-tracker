         const units = ["B", "KB", "MB", "GB"];
         const i = Math.floor(Math.log(bytes) / Math.log(1024));
         return `${(bytes / Math.pow(1024, i)).toFixed(i === 0 ? 0 : 1)} ${units[i]}`;

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Server Action | Untrusted file metadata (chartId, filename, mimeType, fileSize) crosses boundary |
| Server Action -> R2 | Presigned URLs scoped to specific keys; client uploads directly to R2 |
| Client -> R2 (presigned PUT) | File content crosses boundary; limited by presigned URL scope |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Spoofing | addChartFile | mitigate | requireAuth() + chart ownership verification before any DB write |
| T-15-02 | Tampering | addChartFile | mitigate | Zod validation at server action boundary; file type allowlist enforced at presigned URL generation |
| T-15-03 | Elevation of Privilege | deleteChartFile | mitigate | Verify file.chart.project.userId === user.id before delete; not just auth check |
| T-15-04 | Information Disclosure | getChartFileDownloadUrl | mitigate | Ownership check before generating presigned GET URL; 1-hour expiry |
| T-15-05 | Denial of Service | addChartFile | accept | 10MB per-file limit via presigned URL params; no per-chart file count limit (acceptable for single-user app) |
</threat_model>
