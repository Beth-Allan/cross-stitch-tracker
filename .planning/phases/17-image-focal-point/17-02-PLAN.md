<objective>
Propagate focal point data through all display contexts: update queries to include focalPointX/Y, transform functions to pass them through, and display components to apply CSS object-position.

Purpose: Delivers IMG-02 (focal point respected across all image display contexts per D-07). After this plan, any chart with a saved focal point will display correctly in gallery cards, spotlight, currently stitching cards, buried treasures, genre/designer thumbnails, and shopping accordion.

Note on hero banner blur layer: The blurred background `<Image>` in `hero-cover-banner.tsx` uses `object-cover` but is explicitly EXCLUDED from focal point application. It is a decorative/aesthetic element (aria-hidden, opacity-60, blur-[20px]) where precise positioning is irrelevant — the blur makes any focal point indistinguishable. Per D-06, the hero banner does not apply focal point to its rendering.

Output: All object-cover image contexts apply getObjectPositionStyle, all upstream queries include the fields.
</objective>
