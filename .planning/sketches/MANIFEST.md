# Sketch Manifest

## Design Direction
Quick, efficient, spreadsheet-like supply entry. The user transcribes colour lists from a digital pattern in a side-by-side window. The adding experience should feel like fast data entry — keyboard-driven, always showing progress, minimal clicks. The picker must never obscure the existing list.

## Reference Points
- Google Sheets cell entry / autocomplete
- QuickBooks invoice line items
- Jira backlog grid view
- Accounting journal entry tables
- Terminal/CLI multi-step input
