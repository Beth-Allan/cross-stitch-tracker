# Phase 20 — UI Design Contract

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, calendar cell internal gaps |
| sm | 8px | Compact element spacing, chart bar gaps, table cell padding, calendar day cell internal padding |
| md | 16px | Default element spacing, card padding on mobile |
| lg | 24px | Section padding, card padding on desktop |
| xl | 32px | Space between major activity sections (`space-y-8`) |
| 2xl | 48px | Not used this phase |
| 3xl | 64px | Not used this phase |

Exceptions: Session table rows use 12px vertical padding for comfortable scan density. Calendar day cells use 8px internal padding (DesignOS shows 6px but the spec uses 8px to maintain 4px-grid alignment).

## Color

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-background` | Page surface, tab content area |
| Secondary (30%) | `bg-card` / `ring-foreground/10` | Chart cards, calendar container, session table wrapper, stat counter cards |
| Accent (10%) | `bg-success-muted` / `text-success` / `border-success-border` | Pace cards strip, monthly bar fill, today indicator, trend-up arrows, active sort indicator, photo icon |
| Destructive | `text-destructive` | Not used -- phase is read-only |

Accent reserved for:
- Pace cards row background strip (same `bg-success-muted` + `border-success-border` as Phase 19 MetricsBar)
- Monthly bar chart fill color (`var(--chart-1)` emerald for bars)
- Active/selected bar state (lighter emerald tint)
- Calendar "today" circle (`bg-success` emerald-600 circle on day number)
- Calendar today cell background (`bg-success-muted` light emerald tint)
- Trend-up arrow indicators on pace cards
- Sort active indicator icon in session table
- Camera icon for photo indicator

### Chart palette for multi-project calendar

| Token | Color | Project assignment |
|-------|-------|--------------------|
| `--chart-1` | emerald-600 | 1st project (deterministic by sort order) |
| `--chart-2` | amber-500 | 2nd project |
| `--chart-3` | sky-500 | 3rd project |
| `--chart-4` | violet-600 | 4th project |
| `--chart-5` | rose-600 | 5th project |

Projects cycle through `--chart-1` through `--chart-5` based on stable sort order. Each color generates a muted bg/border/text triplet for calendar session pills (derived at render time, matching DesignOS `projectColorStyles` pattern).

### Secondary semantic colors

| Token | Usage |
|-------|-------|
| `text-muted-foreground` | Labels, secondary text, empty day numbers, axis labels |
| `text-foreground` | Primary values, project names, data content |
| `border-border` | Card borders, table row dividers, calendar grid lines |
| `text-warning` / `bg-warning-muted` | Trend-down indicators on pace cards (amber) |

## Layout Contract

### Activity Tab Order (D-16)

Top-to-bottom, full width within the Activity tab content area:

```
1. PaceCards          -- horizontal strip, full width
   gap: 32px (space-y-8)
2. MonthlyStitchChart -- Card container, full width
   > MonthlyDrillDown (conditional, inline below chart when bar clicked)
   gap: 32px (space-y-8)
3. DayOfWeekChart     -- Card container (see responsive note below)
   gap: 32px (space-y-8)
4. StitchingCalendar  -- Card container, full width
   gap: 32px (space-y-8)
5. SessionHistoryTable -- Card container, full width
```

### Responsive Behavior

| Breakpoint | PaceCards | Charts | Calendar | Table |
|------------|-----------|--------|----------|-------|
| `< sm` (mobile) | 2x2 grid | Stacked full-width | 7-col compact, dot indicators instead of pills, tap day for detail | Horizontal scroll, 5 columns |
| `sm-md` (tablet) | 2x2 grid | Stacked full-width | 7-col with truncated pills | Full table |
| `>= md` (desktop) | Flex row (4 across) | Full-width stacked | 7-col with full project pills + stitch counts | Full table |

Day-of-week chart: always full width (7 bars are narrow enough). Monthly chart: always full width. Both stacked vertically -- side-by-side layout rejected because the monthly chart needs horizontal space for 12 bars.

## Interaction Contract

### Monthly Stitch Chart (D-01 through D-04)

| Interaction | Behavior |
|-------------|----------|
| Click bar (non-zero) | Expand inline drill-down panel below chart showing that month's daily session breakdown |
| Click same bar again | Collapse drill-down panel |
| Click different bar | Switch drill-down to new month (no intermediate collapse) |
| Click chart background | Collapse drill-down panel |
| Hover bar | Recharts tooltip showing month name + stitch count |
| Year navigation arrows | Prev/next year buttons flanking the heading. Updates chart data via server action query |
| Empty bar (0 stitches) | No click handler, muted fill color |

### Monthly Drill-Down Panel

| Element | Behavior |
|---------|----------|
| Container | Card below the chart, same width. Animated expand/collapse with `transition-all` + `max-height` or `grid-rows` technique |
| Content | List of daily entries: date (Mon short format), project name (clickable link to `/projects/[id]`), stitch count (right-aligned tabular nums) |
| Heading | Month + Year label, total stitch count for the month |
| Max height | Scrollable at 10+ entries, `max-h-60 overflow-y-auto` |

### Stitching Calendar (D-05 through D-08)

| Interaction | Behavior |
|-------------|----------|
| Month navigation | ChevronLeft / ChevronRight buttons flanking the month name. Triggers server action to fetch that month's data |
| Click session pill | Navigate to `/projects/[projectId]` (Next.js Link) |
| Today indicator | Day number displayed in a 20px emerald-600 circle with white text. Cell background `bg-success-muted` |
| Empty days | No pills, just the day number in muted text |
| Padding cells | Greyed-out background (`bg-muted`), no day number |
| Mobile tap day | On `< sm` breakpoint, tapping a day with activity shows a small popover/tooltip with session details |

### Session History Table (D-09 through D-12)

| Interaction | Behavior |
|-------------|----------|
| Sort by Date | Toggle asc/desc, server-side via URL query param. Default: newest first |
| Sort by Stitches | Toggle asc/desc, server-side |
| Sort by Time | Toggle asc/desc, server-side |
| Project filter | Select dropdown above table. "All Projects" default. Filters server-side |
| Pagination | 25 sessions per page. Prev/Next buttons below table. Page number as URL query param |
| Click project name | Navigate to `/projects/[projectId]` (Next.js Link) |
| Photo indicator | Camera icon (no click action -- view only) |
| No edit button | Read-only on stats page (D-11) |

### Pace Cards (D-14, D-15)

| Element | Behavior |
|---------|----------|
| Trend arrows | Up arrow + green text for positive MoM change, down arrow + amber text for negative |
| Stitch rate | Only displayed when time data is available. Shows "stitches/hr" with trend direction |
| Cards are static | No click interactions -- informational display only |

### Accessibility: Icon-Only Button Labels

All icon-only navigation buttons must include an explicit `aria-label`:

| Button | Icon | aria-label |
|--------|------|------------|
| Monthly chart previous year | `ChevronLeft` | `"Previous year"` |
| Monthly chart next year | `ChevronRight` | `"Next year"` |
| Calendar previous month | `ChevronLeft` | `"Previous month"` |
| Calendar next month | `ChevronRight` | `"Next month"` |

## Calendar Visual Contract

### Day Cell Structure

```
+------------------+
| 15               |  <- day number (12px, muted) or today circle
| [Project A  198] |  <- session pill (colored bg, 10px project name + stitch count)
| [Project B  356] |  <- second pill if multiple sessions
+------------------+
```

### Session Pill Colors

Each project gets a deterministic color from `--chart-1` through `--chart-5`. The pill renders:
- Background: chart color at 15% opacity (muted tint)
- Border: chart color at 40% opacity
- Text: chart color at full saturation

Implementation: generate HSL/OKLCH tint variants from the chart CSS variables at render time, or maintain a lookup of pre-computed muted/border/text triplets (matching the DesignOS `projectColorStyles` approach).

### Calendar Legend

Below the calendar grid, a footer row with project color swatches (10px rounded squares) + project names. Wraps on narrow screens.

### Mobile Calendar (< sm breakpoint)

- Keep 7-column grid but shrink cell min-height from 80px to 48px
- Replace session pills with colored dots (4px circles)
- Tap a day to show a small tooltip/popover listing sessions for that day
- Legend hidden on mobile to save space

## Data Flow Contract

### Server Component (page.tsx) fetches:

| Query | Data | Cache TTL |
|-------|------|-----------|
| `getMonthlyTotals(year)` | 12 months of stitch totals | 5 min (current year), 1 hr (past years) |
| `getCalendarDays(month, year)` | Calendar day data for one month | 5 min (current month), 1 hr (past months) |
| `getSessionHistory(page, sort, filter)` | Paginated session list | 5 min |
| `getPaceMetrics()` | Rolling averages, MoM, stitch rate | 5 min |
| `getDayOfWeekPattern()` | Average stitches per weekday | 5 min |
| `getDailyBreakdown(month, year)` | Daily entries for drill-down | Fetched on-demand client-side via server action |

### Client Interactions triggering server:

| Action | Server Call | URL State |
|--------|-------------|-----------|
| Year navigation (monthly chart) | `getMonthlyTotals(newYear)` | No URL change (component state) |
| Month navigation (calendar) | `getCalendarDays(newMonth, newYear)` | No URL change (component state) |
| Bar click (drill-down) | `getDailyBreakdown(month, year)` | No URL change (component state) |
| Sort column click | Re-fetch page with sort params | `?sort=date&dir=desc` |
| Project filter change | Re-fetch page with filter param | `?project=all` or `?project={id}` |
| Page navigation | Re-fetch page with page param | `?page=1` |
