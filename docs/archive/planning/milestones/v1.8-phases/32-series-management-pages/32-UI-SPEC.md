## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, `gap-1` / `p-1` |
| sm | 8px | Compact element spacing, `gap-2` / `p-2`, sort pill internal padding |
| md | 16px | Card internal padding, `gap-4` / `p-4`, chart row padding |
| lg | 24px | Section spacing between header/sort/grid, `gap-6` / `space-y-6` |
| xl | 32px | Layout gaps, `gap-8` |
| 2xl | 48px | Empty state vertical padding, `py-12` |

Exceptions:
- Card padding: `p-5` (20px) matches DesignOS series card padding. This is a DesignOS-specified value, not a new token.
- Chart row thumbnails: 40px (`h-10 w-10`) for consistency with existing designer detail chart rows.
- Icon button padding: `p-1.5` (6px) on edit/delete action buttons — inherited from existing designer detail styling.
- Chevron kerning: `ml-0.5` (2px) optical micro-adjustment on sort pill chevron icons — inherited from existing patterns.

**Executor guidance:** These exceptions are inherited from DesignOS and existing patterns. Do not introduce additional non-standard spacing values beyond this list.

## Component Interaction Contracts

### CP-01: Series Card (List Page)

| Property | Value |
|----------|-------|
| Container | `bg-card border-border rounded-xl border p-5 hover:shadow-md hover:border-border/80 transition-all cursor-pointer` |
| Grid layout | `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4` |
| Card click | Navigate to `/series/[id]` (entire card is clickable via `<Link>`) |
| Series name | `text-sm font-semibold font-heading text-foreground` |
| Designer line | `text-xs text-muted-foreground mt-0.5` -- "by {designerName}". Only rendered when `designerId` is non-null. No blank space when absent. (D-04) |
| Progress bar | `h-2 rounded-full bg-muted overflow-hidden` container, `h-full rounded-full bg-primary` fill. Width = `finishedCount / ownedCount * 100` percent. (D-01) |
| Stat text (totalCount set) | `text-xs text-muted-foreground`: "{finishedCount} of {ownedCount} finished". Secondary line below: "{ownedCount} of {totalCount} owned". (D-02) |
| Stat text (open-ended) | `text-xs text-muted-foreground`: "{finishedCount} finished · {ownedCount} charts". (D-02) |
| Completion percent | `text-sm font-semibold text-primary` -- right-aligned on stat row. Shows `Math.round(finishedCount / ownedCount * 100)%`. Shows "0%" when ownedCount is 0. |
| 0-chart series | Progress bar hidden (or 0-width). Stat line: "0 charts". Percent: "0%". |

### CP-02: Sort Bar (List Page)

| Property | Value |
|----------|-------|
| Layout | `flex items-center gap-2` with "SORT BY" label prefix |
| Label | `text-xs text-muted-foreground uppercase tracking-widest font-semibold mr-2` |
| Sort options | "Name" (default, asc), "Completion", "Charts" (D-05, D-06) |
| Active pill | `bg-success-muted text-success-muted-foreground font-semibold rounded-full px-3 py-1` + chevron icon (matches designer detail sort pill pattern) |
| Inactive pill | `text-muted-foreground hover:text-foreground rounded-full px-3 py-1 transition-colors` |
| Chevron | `ChevronUp` for asc, `ChevronDown` for desc. `h-3 w-3 inline ml-0.5` |
| Sort key "Name" | Alphabetical by `series.name` |
| Sort key "Completion" | By `finishedCount / ownedCount` percentage. 0-chart series sort to bottom. (D-05) |
| Sort key "Charts" | By `ownedCount` (total assigned charts) |
| State management | `useState` in client component (not URL params -- matches designer pattern) |

## Visual Hierarchy

**List page primary focal point:** The series card grid is the primary visual anchor. The page title ("Series") and "Add Series" CTA button form the header bar, followed by the sort bar, then the card grid which occupies the majority of viewport. When no series exist, the empty state (centered icon + heading + CTA) is the sole focal point.

**Detail page primary focal point:** The series name heading at `text-2xl` with the progress bar immediately below it. The chart list section is the secondary focal region.

## Accessibility Contract

| Requirement | ARIA Pattern | Test Approach |
|-------------|-------------|---------------|
| Series card clickability | `<Link>` wrapping full card, inherits accessible name from series name heading inside | Verify card renders as `<a>` with href, contains series name |
| Sort pills keyboard | `type="button"` on all sort buttons, `aria-label` not needed (visible label) | Tab to pills, Enter/Space toggles sort |
| Inline name edit | Input receives focus on edit mode entry. `aria-label="Series name"` on input | Verify focus moves to input on Pencil click |
| Edit series name icon button | `aria-label="Edit series name"` on Pencil icon button adjacent to series name | Verify accessible name present on icon-only button |
| Edit designer icon button | `aria-label="Edit designer"` on Pencil icon button adjacent to designer display | Verify accessible name present on icon-only button |
| Delete series icon button | `aria-label="Delete series"` on Trash2 icon button in detail header actions | Verify accessible name present on icon-only button |
| Delete confirmation | Dialog uses `DialogTitle` + `DialogDescription` for screen reader context | Verify dialog has `role="dialog"`, title, description |
| Chart rows | `<Link>` with chart name visible. `role="group"` not needed (Link is self-describing) | Navigate by Tab, Enter activates link |
| Loading skeleton | `aria-hidden="true"` on skeleton container, `aria-label="Loading series"` on page wrapper | Verify skeleton is hidden from screen readers |
| Empty state | EmptyState component renders heading text and description for screen readers | Verify heading/description text present |
