## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, label-to-dot spacing |
| sm | 8px | Compact element spacing, input vertical padding |
| md | 16px | Default element spacing, card padding vertical |
| lg | 24px | Section divider vertical margin, field group margin-bottom |
| xl | 32px | Page horizontal padding (mobile) |
| 2xl | 48px | Page vertical padding top |
| 3xl | 64px | Sticky save bar clearance (bottom padding on form) |

Exceptions:
- Pattern type card internal padding: 12px vertical, 16px horizontal (matches sketch `var(--space-3) var(--space-4)`)
- Input padding: 8px vertical, 12px horizontal (matches sketch spec)
- Genre chip padding: 4px vertical, 12px horizontal (existing pattern, matches sketch)
- Required dot: 6px diameter with 6px right margin (sketch spec)

### Page Structure

```
page-wrap (max-w-[720px] mx-auto px-5 lg:px-8 pt-12 pb-20)
  back-link ("< Charts")
  page-title ("Add New Chart") + page-subtitle ("Create a chart and set up your project")
  <form>
    IDENTITY GROUP

      Designer (SearchableSelect + inline add)
      Cover Image (CoverImageUpload)
      Genres (GenrePicker chips)
    <hr> section-divider
```

### Responsive Behavior

- Max width: 720px centered
- Horizontal padding: `px-5` (20px mobile), `lg:px-8` (32px desktop)
- 3-column grids (stitch count, dates): collapse to stacked on `< 480px` via `grid-cols-1 sm:grid-cols-3`
- Pattern type cards: 2-column grid, collapse to stacked on `< 400px` via `grid-cols-1 sm:grid-cols-2`
- Sticky save bar: full-width fixed bottom, content centered at 720px max-width

## Required Dot Indicator

The sketch spec calls for a green 6px dot before required field labels, replacing the current red asterisk.

**Implementation:** Modify `FormField` to render a green dot when `required` is true.

```
.req-dot
  display: inline-block
  width: 6px, height: 6px
  border-radius: 50%
  background: var(--primary) (emerald-600)
  margin-right: 6px
  vertical-align: middle
  position: relative, top: -1px
```

Tailwind equivalent:
```
<span className="bg-primary mr-1.5 inline-block size-1.5 rounded-full align-middle relative -top-px" aria-hidden="true" />
```

Applied to exactly 2 fields: **Chart Name** and **Status**. All other fields are implicitly optional — no "optional" labels.

## Pattern Type Cards

### Visual Spec

2-column grid with 12px gap (`grid grid-cols-2 gap-3`).

Each card:
- Border: `border border-border rounded-md` (radius-md = 0.4rem)
- Padding: `py-3 px-4` (12px / 16px)
- Background: `bg-card` (white)
- Cursor: pointer
- Transition: `transition-all duration-150`

Selected state:
- Border: `border-primary`
- Background: `bg-primary/[0.03]` (emerald at 3% opacity)
- Box shadow: `ring-1 ring-primary`

### Check Circle

Top-right corner of each card, 18px diameter circle:
- Unselected: `border-2 border-border` circle, empty
- Selected: `border-primary bg-primary` circle with white checkmark icon (Lucide `Check`, 12px)

### Card Behavior

**Paper / Digital pair:** Mutually exclusive (radio behavior). Selecting Paper deselects Digital and vice versa. Maps to `isPaperChart: true` (Paper) / `isPaperChart: false` (Digital).

**Kit / SAL pair:** Independent toggles (checkbox behavior). Can co-exist with each other and with either Paper or Digital. Map to `isFormalKit` and `isSAL` booleans.

### Expandable Sub-Field

Kit card only: when selected, expands to show "Colours in kit" numeric input.
- Animation: `max-height` transition from 0 to 80px, opacity 0 to 1, duration 250ms ease
- Input: standard `<Input>` component, `max-w-[200px]`, inside the card below the title

### Default State

On load: Digital selected (isPaperChart=false), Kit and SAL unselected. This matches the existing default in `useChartForm`.

## Draft Persistence (Save Draft)

### localStorage Contract

- Key: `"chart-draft"` (single draft slot)
- Value: JSON serialization of form state from `useChartForm` values object
- Debounce: not applicable — Save Draft is an explicit button click, not auto-save
- Hydration: on mount, check localStorage for `"chart-draft"`. If found, parse and populate form. Show sonner info toast "Draft restored".
- Stale ID handling: if a referenced designerId/storageLocationId/stitchingAppId no longer exists in the provided lists, set to null silently
- Clear: remove localStorage key on successful `createChart` submission

## Interaction States

### Focus

All inputs use the existing shadcn/Base UI focus ring pattern:
- `outline-ring/50` (from globals.css base layer)
- Custom inputs (pattern type cards): `ring-2 ring-primary/15` on focus-visible

### Hover

- Pattern type cards: `hover:border-primary/30` when unselected
- Genre chips: existing hover pattern (border opacity change)
- Buttons: shadcn default hover variants

### Disabled

- Create/Save Draft buttons: disabled when chart name is empty
- Create button: disabled during submission (`isPending`)
- Kit color count input: only visible when Kit card is selected

### Loading

- Create button: "Creating..." text + disabled state during submission
- Save Draft button: "Saving..." text + disabled state during localStorage write (effectively instant, but consistent UX)

## Accessibility

- Pattern type cards: `role="radiogroup"` for Paper/Digital pair, individual cards use `role="radio"` + `aria-checked`
- Kit/SAL cards: `role="checkbox"` + `aria-checked`
- Required fields: green dot is `aria-hidden="true"`, `<span className="sr-only"> (required)</span>` provides screen reader text (existing FormField pattern adapted)
- Sticky save bar: `role="toolbar"` + `aria-label="Form actions"`
- Section dividers: `<hr>` elements (semantic separator, no special ARIA needed)
- Back link: visible focus ring, arrow icon decorative (`aria-hidden`)
- Form errors: `role="alert"` on error messages (existing pattern)
- Milestone marker: static decorative in Phase 12, no interactive ARIA needed
