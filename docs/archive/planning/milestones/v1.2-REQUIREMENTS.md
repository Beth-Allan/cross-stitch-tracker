## v1.2 Requirements (All Complete)

### Session Logging

- [x] **SESS-01**: User can log a stitch session with date, project, stitch count, and optional time/photo — *Satisfied: LogSessionModal + createSession with photo upload via R2*
- [x] **SESS-02**: User can access the Log Session modal from the header button, project detail, and dashboard — *Satisfied: TopBar button, ProjectSessionsTab button, QuickAddMenu DOM event*
- [x] **SESS-03**: User can view per-project session history with mini stats (total stitches, sessions logged, avg per session, active since) — *Satisfied: ProjectSessionsTab with 4 mini-stat cards and sortable SessionTable*
- [x] **SESS-04**: User can edit or delete an existing session — *Satisfied: updateSession/deleteSession in actions, edit modal with two-step delete*
- [x] **SESS-05**: Project progress auto-updates when sessions are created, edited, or deleted (atomic with session mutation) — *Satisfied: $transaction in all 3 mutation actions, conditional read-only stitchesCompleted*
- [x] **SESS-06**: User can upload a progress photo with a session (reuses existing R2 upload pattern) — *Satisfied: Upload category "sessions", photo upload in LogSessionModal*

- [x] **DASH-03**: User sees a "Buried Treasures" section surfacing the oldest unstarted charts with days-in-library count — *Satisfied: getBuriedTreasures returns oldest 10% unstarted (max 5)*
- [x] **DASH-04**: User sees a "Spotlight" card featuring a random project with a refresh button — *Satisfied: getSpotlightProject with server-side random skip, shuffle button*
- [x] **DASH-05**: User sees a Collection Stats sidebar (total projects, WIP/hold/unstarted/finished counts, total stitches, most recent finish, largest project) — *Satisfied: getCollectionStats computes all 8 values, mobile collapse*
- [x] **DASH-06**: User can access a Quick Add menu to create charts, supplies, designers, or log stitches — *Satisfied: QuickAddMenu with 8 items, Log Stitches via custom DOM event*

- [x] **PDIV-03**: User can view a "What's Next" tab showing projects ranked by kitting readiness and start-next flag — *Satisfied: getWhatsNextProjects with kitting calculation, WhatsNextTab renders cards*
