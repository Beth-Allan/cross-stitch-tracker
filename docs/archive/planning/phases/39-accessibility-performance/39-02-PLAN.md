<objective>
Add useMemo to SupplyOverview aggregation/filtering calls and fix the SSR hydration mismatch in SupplyCatalog's view mode initialization (per POLISH-04 / backlog 999.58, 999.72).

Purpose: SupplyOverview recomputes `aggregateSupplies()` and `filterAggregatedSupplies()` on every render (triggered by pendingIds/failedIds changes from quantity updates). Wrapping in useMemo prevents unnecessary recalculation. SupplyCatalog reads localStorage in a useState initializer via `typeof window !== "undefined"`, which causes React hydration warnings because server renders DEFAULT_VIEWS but client may render localStorage values. Replacing with a useEffect post-mount pattern eliminates the mismatch.

Output: Memoized supply aggregation, SSR-safe view mode initialization, matching tests.
</objective>
